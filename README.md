# SMB Manager V2

Веб-панель для управления Samba/SMB: пользователи, SMB-папки и права RO/RW.

## Запуск

```bash
cp .env.example .env
# обязательно задайте ADMIN_TOKEN

docker compose up -d --build
```

Открыть:

`http://SERVER_IP:8080`

При первом открытии браузер попросит `ADMIN_TOKEN` из `.env`.

SMB:

`\\SERVER_IP\ИмяПапки`

## V2 UI

- React + Vite SPA
- современная административная панель
- Dashboard со статистикой
- пользователи: создание, удаление
- SMB-папки: создание, удаление
- управление доступом RO/RW
- светлая/тёмная тема
- адаптивная верстка
- API проксируется через nginx

## Важно

Docker Compose должен запускаться на Linux-хосте с возможностью публиковать TCP 445/139. Перед использованием в production следует добавить полноценную аутентификацию администратора, HTTPS и резервное копирование state/volumes.
